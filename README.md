# team-portfolio

Alpha Circle team portfolio website for showcasing members, projects, and contact details.

## About

This repo contains a static HTML/CSS/JS portfolio for the Alpha Circle team. It includes:

- Homepage hero section with animated interaction.
- About section and team member cards.
- Individual member profile pages with GitHub and LinkedIn contact links.
- Project showcases and contact section.

## Run locally

Open index.html in a browser or serve from a local static server.
